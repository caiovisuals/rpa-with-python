## Aviso sobre regras tributárias

Este projeto **não contém regras tributárias presumidas**. Alíquotas, faixas, bases de
cálculo, tetos e arredondamento serão carregados de tabelas parametrizadas por vigência,
preenchidas a partir de fonte oficial e homologadas por profissional de contabilidade
antes de qualquer uso em produção.
